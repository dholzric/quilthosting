Forms

Surveys, applications and contact forms, and the quote-request form on business sites.

Building a form

Admin → Forms. A form has a title, an address (used in links), a type (survey, application or general), and up to 40 fields. Field types: text, textarea (a paragraph), select (a dropdown with options), checkbox, email and number; each can be required. A field can be shown only when another field has a certain value (equals, does not equal, contains, is not empty); hidden fields are never required.

Fields are currently entered as a short list in a text box rather than a drag-and-drop editor; the screen shows an example to copy. Answers are checked when submitted: required fields, dropdown options, email format and numbers. Each answer is kept to 2,000 characters.

Owners, admins, membership chairs and events chairs can build forms.

The contact form block

On business sites, add the Contact form section to a page in the website builder. It shows a name, email and message form and files each message as a response to the form whose address you chose (default contact). Create that form first under Admin → Forms so the responses have somewhere to go.

Responses

Open the form under Admin → Forms to see the last 500 responses with their answers. When the sender's email matches a member, the response is linked to them. No email is sent to the guild when a form is submitted, so check the screen — or connect a Zapier webhook to the form.response event (see API & Zapier) to be notified. There is no CSV download for responses yet.

Quote requests (business sites)

Business sites have a separate Quote request section that collects a customer's project details and photos and creates a project rather than a form response. The customer receives an acknowledgement and the business owner is emailed. See Business sites.
