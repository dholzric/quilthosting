Website, logo & store

Your public face: join page, branding, content, embeds, and shop.

Public guild page

https://quilthosting.com/g/your-slug

Includes membership levels, upcoming events, store, donations (if enabled), blog, content pages, and optional public directory.

Guild logo

Admin → Settings → Public profile → Guild logo.

  • Formats: PNG, JPEG, WebP, GIF, SVG
  • Max size: 2 MB
  • Shown next to the guild name on /g/:slug and on join embeds
  • Public URL: /public/:slug/logo
Square or horizontal logos work best. Transparent PNG recommended.

Website builder

Admin → Website.

Theme

  • Primary color, style (classic / modern / warm), font
  • Custom nav links as JSON: [{"label":"QuiltMap","href":"https://quiltmap.com"}]

Pages

Create published or draft pages. Options: members-only, show in nav.

Blocks JSON (preferred) — example:

[
  {"type":"heading","text":"About us","level":2},
  {"type":"text","html":"<p>We meet monthly…</p>"},
  {"type":"image","url":"https://…","alt":"Guild quilt"},
  {"type":"button","label":"Join","href":"#h-membership"},
  {"type":"join_cta","title":"Become a member"},
  {"type":"events_list","limit":5},
  {"type":"store_list","limit":6},
  {"type":"divider"},
  {"type":"html","html":"<p>Custom markup</p>"}
]

You can still paste plain HTML in the content box if you prefer.

Blog

Admin → Blog. Posts appear on the public page under Blog. Not mixed into regular nav pages.

Embeds (WordPress, etc.)

Copy from Settings or use:

<iframe src="https://quilthosting.com/embed/YOUR-SLUG/join"
  width="100%" height="520" style="border:0;max-width:440px"
  loading="lazy"></iframe>

Paths: /embed/:slug/join, /events, /store.

Store, cart & tax

  1. Admin → Store → add products (price in cents, optional inventory & SKU).
  2. Set tax rate in basis points (e.g. 700 = 7.00%) and tax label.
  3. Mark products taxable or not.
  4. On the public page, visitors add to cart and checkout (multi-SKU + tax line).

“Buy now” still works for a single product. Free products fulfill without Stripe.
