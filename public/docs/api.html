Public API (v1)

Use API keys from Admin → API for Zapier, Make, or custom integrations. Keys are shown once at creation.

Authentication

Authorization: Bearer qh_…your_key…

Optional query form (less secure): ?api_key=qh_…

Endpoints

GET /api/v1/me
GET /api/v1/members?status=active
GET /api/v1/events
GET /api/v1/payments
GET /api/v1/levels

Zapier (no native app yet)

  1. Create a read key in QuiltHosting Admin → API.
  2. In Zapier, use Webhooks by Zapier (GET) or Code by Zapier with fetch.
  3. Poll GET /api/v1/members or /payments on a schedule, or push outbound from your own Zap when QuiltHosting emails fire.
  4. For member-created events, map fields: email, first_name, last_name, status, joined_at.

Example

curl -s https://quilthosting.com/api/v1/members \
  -H "Authorization: Bearer qh_…" | jq '.members[0:3]'
