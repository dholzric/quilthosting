Members

  • Statuses: pending, active, lapsed, cancelled
  • Custom fields: defined in Settings; optional on join form
  • Assign level offline: mark paid when dues collected in cash/check
  • Directory: members can opt out; public directory is opt-in on the guild profile

Events

  • Member vs non-member pricing; capacity with pending_payment hold
  • Registration questions (text/select, required)
  • Waitlist + promote with email
  • Ticket codes; check-in from event detail (works offline in the PWA)

Store

Products with optional inventory, SKU, and taxable flag. Set tax rate in basis points (700 = 7%) under Store. Public page supports multi-item cart. Details: Website & store.

Invoices

Create multi-line invoices (description | qty | unit cents). Numbers look like INV-2026-00001. Print from the admin list. Mark paid when settled outside Stripe if needed.

Forms & surveys

Build fields in JSON, including conditionals:

{
  "key": "brand",
  "label": "Longarm brand",
  "type": "text",
  "show_if": { "field": "longarm", "op": "equals", "value": "Yes" }
}

Public submit: POST /public/:slug/forms/:formSlug. View responses in Admin → Forms.

Team roles

Invite teammates from Admin → Team. Nav is filtered by role.

SMS

Optional. In SMS settings, save Twilio Account SID, Auth Token, and From number (stored in guild settings). Without Twilio, messages are logged as queued.

Chapters (Council)

Parent guild can create child chapters (each with own slug, members, events). Chapters cannot nest further. Archive a chapter when retiring it.

PWA / offline check-in

On a phone: open Admin → “Add to Home Screen”. Event check-in queues offline and syncs when back online.
