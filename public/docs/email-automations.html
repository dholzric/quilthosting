Email & automations

Newsletters, segments, tracking, and multi-step welcome series.

Blasts

Admin → Email.

  • Segment by status, membership level, or member group
  • Layouts: plain, newsletter, announcement
  • Schedule send for later (daily job delivers due blasts)
  • Delivery log with open counts

Merge fields

Use in subject or body:

{{first_name}}  {{last_name}}  {{email}}
{{guild_name}}  {{level_name}}  {{end_date}}

Also accepts single-brace form {first_name}. Unknown fields become empty (first name falls back to “there”).

Open & click tracking

  • Opens: 1×1 pixel on blasts → updates email_logs
  • Clicks: http(s) links rewritten through /t/c/:logId?u=…

Tracking paths are exempt from the site password gate so mail clients can load them.

Welcome automations

Admin → Automations. Create a sequence triggered on member_activated with steps:

[
  {
    "delay_days": 0,
    "subject": "Welcome to {{guild_name}}!",
    "body_html": "<p>Hi {{first_name}}, …</p>"
  },
  {
    "delay_days": 3,
    "subject": "Getting started",
    "body_html": "<p>Renewals, events, portal…</p>"
  }
]

The daily cron enrolls new actives and sends due steps. Pause or delete sequences anytime.
