Getting started

Set up a new guild in about an hour. Work through the checklist in order.

Launch checklist

  1. Sign in at /admin (Google sign-in in production).
  2. Create your guild (name + URL slug).
  3. Add at least one membership level with price and duration.
  4. Connect Stripe Express so dues land in the guild bank.
  5. Import or add members; send a welcome email when ready.
  6. Upload your guild logo and fill public profile text.
  7. Share your public link: /g/your-slug.
  8. Create an event; test registration as a non-member.
  9. Optional: store products, embeds for WordPress, API key for Zapier.

Create your guild

After login, choose Create guild. Pick a short slug (letters, numbers, hyphens) — it becomes:

https://quilthosting.com/g/your-slug
https://quilthosting.com/portal?slug=your-slug

New guilds start on a 30-day Guild trial (unlimited active members) without a card.

Membership levels

Admin → Levels. For each tier set:

  • Name — e.g. Individual, Family, Lifetime
  • Price — in cents (2500 = $25.00). Zero = free activation.
  • Duration — months until renewal
  • Renewal — manual (member pays each year) or auto (Stripe subscription)
Soft-archive levels instead of deleting if members ever held them — keeps history clean.

Connect Stripe

Admin → Settings → Billing & payouts → Connect bank account. This uses Stripe Connect Express. Until Connect is complete, test payments may still work in sandbox, but guild bank deposits need a linked account.

See Billing & payments for platform Guild plan ($24/mo after trial) vs member dues.

Import members

Admin → Members → Import. CSV headers are Wild Apricot–compatible where possible. You can map level and expiry on import. Or add members one-by-one.

Public page & logo

  • Public join/events/store: /g/your-slug
  • Logo + about text: Settings → Public profile
  • Pages, theme, nav: Admin → Website
  • WordPress embeds: Settings → Embed widgets, or Website & store
