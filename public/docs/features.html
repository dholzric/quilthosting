Feature reference

Capability map for QuiltHosting v0.20+ (quilt-guild AMS).

Membership

  • Multi-level dues, manual/auto renewal, soft-archive levels
  • Member database with custom fields, notes, CSV import/export
  • Renewal reminders, auto-lapse, win-back
  • Plan free ≤30 / Guild $24 / 30-day trial

Events

  • Registration, dual pricing, capacity, waitlist + promote email
  • Custom questions, tickets, check-in, offline PWA queue

Communications

  • Blasts: status/level/group segments, layouts, schedule
  • Merge fields, open + click tracking
  • Multi-step welcome automations
  • Optional SMS (Twilio)

Website & content

  • Public /g/:slug, logo, theme, block pages, blog
  • Embeds for join / events / store
  • Documents library, members-only pages
  • Member forum

Commerce

  • Store products, inventory, SKU, tax BPS, multi-SKU cart
  • Donations with receipt email
  • Numbered multi-line invoices
  • One-click refunds; QBO IIF export

Integrations & ops

  • Stripe Connect destination charges + platform billing
  • Public API v1 + API keys (Zapier-ready)
  • Multi-chapter Council
  • Role-based team access; site gate for stealth launch
  • Scale: paginated members/payments, queued email blasts, indexes for 50k+ members (see docs/scaling.md)

Not included (by design)

  • Native iOS/Android apps (use PWA)
  • Job board
  • Full Wild Apricot drag-drop CMS parity
  • Zapier marketplace listing (REST works; listing later)
