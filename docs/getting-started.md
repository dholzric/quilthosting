# Getting started

Product HTML: [/docs/getting-started.html](../public/docs/getting-started.html)

## Launch checklist

1. Sign in at `/admin`
2. Create guild (name + slug)
3. Add membership levels
4. Connect Stripe Express (Settings → Billing)
5. Import/add members
6. Upload guild logo + public profile
7. Share `/g/your-slug` and `/portal?slug=your-slug`
8. Create a test event; optional store, embeds, API key
